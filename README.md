## Project Overview

Async Race is a Single Page Application (SPA) for managing a collection of cars, running drag races, and tracking winners statistics.

## Tech Stack

- React 18
- TypeScript
- Redux Toolkit
- React Router
- Vite
- CSS Modules
- ESLint (Airbnb)
- Prettier

## Basic Structure (20 / 80 points)

- [x] **Two Views (10 pts):** Implemented primary navigation views: "Garage" and "Winners".
- [x] **Garage View Content (30 pts):** Displays garage controls, race controls and garage list.

## Garage View (50 / 90 points)

- [x] **CRUD Operations (20 pts):** Create, update and delete cars functionality implemented.
- [x] **Color Selection (10 pts):** RGB color picker integrated with car rendering.
- [x] **Random Car Creation (20 pts):** Generates random cars with random names and colors.
- [x] **Car Management (10 pts):** Edit and delete actions implemented for every car.
- [x] **Empty Garage (10 pts - EXTRA):** Empty garage state implemented.
