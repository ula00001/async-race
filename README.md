## Project Overview

Async Race is a Single Page Application (SPA) for managing a collection of cars, running drag races, and tracking winners statistics.

- TypeScript
- Redux Toolkit
- React Router
- Vite
- CSS Modules
- ESLint (Airbnb)
- Prettier
